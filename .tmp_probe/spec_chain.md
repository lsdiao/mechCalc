## 一、公式提取结论（全部经探针逐值验证）

| 量 | 公式 | 备注 |
|---|---|---|
| 设计功率 | `Pc = f1·f2·P / km` | 显示 2 位小数；P6: 2.1·0.79·100.5=166.7295→166.73 |
| 工况系数 f1 | 表 [从动机况][主动机况]，GB/T 18150-2000 | 运转平稳行 1/1.1/1.3；中等冲击行 1.4/1.5/1.7；严重冲击行 1.8/1.9/2.1 |
| 齿数系数 f2 | `f2 = (19/z1)^1.08` | 原站字段按 2 位小数填入后再参与计算 |
| 排数系数 km | 单排 1 / 双排 1.75 / 三排 2.5 | |
| 最小中心距 | `i<4: a0min=0.2·z1·(i+1)`；`i≥4: a0min=0.33·z1·(i−1)` | 单位：节 p；原站 HTML 静态默认 9.5(=0.2·19·2.5) 与其 JS 不一致，以 JS 为准 |
| 链长节数 | `X0 = 2a0 + (z1+z2)/2 + (z2−z1)²/(4π²·a0)` | a0 以节数计；显示 2 位 |
| 圆整 | `X = ceil(X0)`，奇数则 +1（**向上取偶**） | 74.57→76、94.23→96、101.86→102（恰偶不变）、54.74→56 |
| 链长 | `L = X·p/1000` m | 3 位小数 |
| 链速 | `v = z2·n2·p/60000`（=z1·n1·p/60000，n1=n2·z2/z1） | 2 位；**F 用未舍入 v**（5000/3.01625=1657.6875→1657.69，若用 3.02 则 1655.63 ✗） |
| 理论中心距 | `a = p/4·[(X−(z1+z2)/2) + √((X−(z1+z2)/2)² − 8((z2−z1)/(2π))²)]` | 未舍入参与后续计算 |
| 实际中心距 | `a·(1−Δa)`，Δa∈[0.002,0.004] | 2 位 |
| 小链轮包角 | `α1 = 180 − 57.3·(z2−z1)/(π·(a/p))` | **系数为 57.3 而非 180/π**：C5(a0=40,z1=17,z2=100,p=31.75) 前者 142.714→142.71=API，后者 142.7168→142.72 ✗；未舍入 a |
| 圆周力 | `F = 1000·P / v` | 2 位 |
| 压轴力 | `FQ = f5·f1·F`，f5∈[1.05,1.2] | **用未舍入 F**：C4 用 1657.69 得 2262.75，API 为 2262.74 → 必须用 1657.6875 |

服务端各输出显示位数：Pc 2、X0 2、X 整数、L 3、v 2、a 2、a实际 2、α1 2、F 2、FQ 2；中间量不提前舍入。

## 四、边界与联动复刻要点

1. a0length（mm）优先反算 a0=a0length/p（E1: 254mm→20p→与 C2 完全一致）。
2. f2 留空自动 `(19/z1)^1.08` 保留 2 位（E2: z1=25→0.74，Pc=1.85）。
3. a0 留空取 a0min；i≥4 分支 E3（i=5→a0min=0.33·19·4=25.08，n2=53，z2=95）。
4. 校验复刻原站文案与范围：P 0~1000、n1/n2 0~5000、i 0~10、z1/z2 17~120（`z2须为17-120之间的数`）、Δa 0.002~0.004、f5 1.05~1.2。
5. 判别式 D<0（a0 过小链长无法闭合）→ 返回错误提示。
6. verdict：a0<a0min 或 α1<120° 给 warn（原站页面标注 α1≥120° 要求；默认参数 a0=9.5<a0min=13.3 触发 warn，与原站 JS 公式一致——原站 HTML 静态默认值 9.5 与其自身 a0min 公式本就矛盾）。

## 五、与原站字段一一对应

输入：power/n1/n2/velocity/transmissionRatio/drivingMachine/drivenMachine/chainNumber/chainType（输入初始参数）；z1/z2/f2（rollerChain1）；chainSize/a0/a0length（rollerChain3）；deltaA/inputFactorF5（计算链条参数）。原站只读/自动字段 f1、km、powerC、chainPitch、a0min、z2、n2、i 均改为计算输出行。
输出：X0→链长节数、X→实际链长节数、L→链条长度、v→链速、a→理论中心距、aAct→实际中心距、α1→小链轮包角、F→有效圆周力、FQ→压轴力（FQ=f5·f1·F，原站公式行）。
链号选择：按 Pc 与 n1 查 GB/T 18150 额定功率图（原站为图表人工选择，本地在结果行给出选链依据并保留链号下拉）。
