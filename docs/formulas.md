# ErinsonCalc 计算公式与数据依据

本站全部计算公式与数据表的出处、修正记录。回归测试：`node tests/run-tests.js`。

## 1. 螺栓连接强度校核（js/tools/connection.js）

- 普通螺纹小径 d₁：GB/T 196-2003《普通螺纹 基本尺寸》
- 性能等级最小屈服强度 σs：GB/T 3098.1《紧固件机械性能 螺栓、螺钉和螺柱》
- 公式：
  - F₀ = F″ + F（总拉力；残余预紧力 F″=k·F，k=0.2 静载 / 0.6 变载 / 1.0 密封 / 1.5 冲击）
  - σca = 1.3·F₀/(π·d₁²/4) ≤ [σ]=σs/S
- 修正记录：总拉力曾误用 F₀=F″+λF，已按《机械设计》第九版 第四章改正为 F₀=F″+F。

## 2. 平键连接强度校核（js/tools/connection.js）

- 键槽剖面尺寸：GB/T 1095-2003《平键 键槽的剖面尺寸》（轴径段→b×h，>95~110 段为 25×14，2026-08 补齐该档并扩展至 d≤500）
- σp = 2T/(d·k·l) ≤ [σp]，k≈0.4h，A 型键 l=L−b
- [σp]：钢 125/100/50，铸铁 70/50/30 MPa（静/轻微冲击/冲击）
- 依据：GB/T 1096-2003；《机械设计》第九版 第六章。

## 3. 压缩弹簧设计（js/tools/connection.js）

- 曲度系数（Wahl）：**K = (4C−1)/(4C−4) + 0.615/C**（曾误用 4C−3，已改正）
- 碳素弹簧钢丝 σb 随直径变化：GB/T 4357-2009《冷拉碳素弹簧钢丝》B 级 / C 级表（B级 d1=1660 → d25=870 MPa），站内按选径插值
- 碳素钢丝许用切应力：[τ]=0.5σb（III类）/0.4σb（II类）/0.3σb（I类）
- d ≥ 1.6√(K·C·F₂/[τ])；n = G·d⁴/(8·D₂³·k)；b=H₀/D₂ ≤ 5.3（两端固定）
- 依据：GB/T 23935-2022、GB/T 1358；《机械设计》第九版 第十六章。

## 4. 滚珠丝杠副（js/tools/linear.js）

- Ca = fw·Fm·(60·n·Lh/10⁶)^(1/3)/fH（GB/T 17587）
- 驱动转矩 T = F·Ph/(2πη)；P(kW) = T·n/9.55×10⁶（T 为 N·mm；曾误除 9.55×10⁵，已改正）
- **临界转速**（THK/NSK 手册）：nc = λ₂·dk/Lb²×10⁷ r/min；λ₂：固定-固定 21.9、固定-支承 15.1、支承-支承 9.7、固定-自由 3.4；工作转速 ≤0.8nc（2026-08 新增）
- **压杆稳定**：Pk = 0.5·η₁·π²·E·I/La²，I=π·dk⁴/64，E=2.06×10⁵ MPa；η₁：4.0/2.0/1.0/0.25（对应上述支承顺序）；轴向载荷 ≤Pk/3（2026-08 新增）
- DmN = Dm·n ≤ 70000（精密研磨级常规值）

## 5. V带传动（js/tools/transmission.js）

- 数据表：GB/T 13575.1-2008《普通和窄V带传动 第1部分：基准宽度制》
  - 单根基本额定功率 P0 全表（Y/Z/A/B/C/D/E × dd1 × n1 双线性插值，2026-08 由近似式改为全表查值并补 Z 型）
  - 弯曲影响系数 Kb（×10⁻³）：Y 0.06、Z 0.39、A 1.03、B 2.65、C 7.50、D 26.6、E 49.8（C 型曾误 3.6232，已改正）
  - 带长修正系数 KL（按 Ld 查表）、每米质量 q（kg/m）、包角修正系数 Kα（表19 插值）
- 公式：
  - ΔP0 = Kb·n₁·(1−1/Ki)（Ki 按传动比区间查表）
  - z = Pd/[(P0+ΔP0)·Kα·KL]
  - F₀ = 500·Pd/(z·v)·(2.5/Kα−1) + q·v²（离心项曾误 0.01v²，已改正为 0.1v² 量级即 q·v²）
  - Q = 2zF₀sin(α₁/2)
- 选型图：GB/T 13575.1 选型图数字化边界 lg n1 = a·lg Pd + b

## 6. 渐开线圆柱齿轮（js/tools/transmission.js）

- 模数系列：GB/T 1357-2008
- d = mn·z/cosβ；da = d + 2(ha*+x−σ)·mn，**σ=(x₁+x₂)−y**（齿顶高变动系数，角变位时防止顶隙过小，2026-08 新增）
- 无侧隙啮合：inv α′ = inv αt + 2(x₁+x₂)tanαn/(z₁+z₂)；a′ = a·cosαt/cosα′
- 公法线长度：**Wk = mn·cosαn·[π(k−0.5)+z·invαt] + 2x·mn·sinαn**（斜齿用实际齿数 z 与端面 invαt；曾误用当量齿数 zv=z/cos³β 于 W 计算与 k 取整混用，2026-08 改正）
- 跨测齿数：k = z′·αn/180°+0.5，z′ = z·invαt/invαn；变位加 2x·cotαn/π 修正
- 依据：GB/T 1357、GB/T 2821、GB/T 6443；《机械设计》第九版 第十章。

## 7. 液压/气压（js/tools/fluid.js）

- 油缸速度 v = Q×10⁶/60/A（Q 以 L/min 计；曾误用 1000 导致 1000 倍偏差，已改正）
- 油缸推力 F = p·A；气缸耗气量按压缩比折算
- 依据：《液压工程手册》《气压传动》通用公式。

## 8. 电机选型（js/tools/selection.js）

- P = T·n/9550；电机功率等级 GB/T 755（3.7kW 非标已移除）

## 9. 公差配合 / 硬度换算 / 钢材重量 / 转动惯量（js/tools/common.js）

- 公差：GB/T 1800.1-2009 标准公差 IT 与基本偏差（孔 K~S 特殊规则 ES=−ei+Δ，Δ=ITn−IT(n−1)）
- 硬度：GB/T 1172-1999 常用段锚点（HRC20→238HV/226HBW … HRC45→446/429 … HRC68→940/872；2026-08 修正 38/40/42/45 等档位数值）
- 六角钢截面积 **A = (√3/2)S² ≈ 0.866S²**（S 为对边距离；曾误用 2.598S²——该系数对应边长平方，导致重量 3 倍偏差，2026-08 改正）
- 理论重量 W = A(mm²)·L(m)·ρ(g/cm³)/1000
- 依据：GB/T 702（六角钢理论重量 0.0068S² kg/m 与本式一致）
